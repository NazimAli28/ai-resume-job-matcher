# Security policy

## Reporting a vulnerability
Please **do not open a public issue** for security problems. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge reports within 3 business days.

## Scope
- The deployed web app and its API routes.
- This repository's code and CI configuration.

Out of scope: denial-of-service testing, social engineering, and findings in third-party services (Supabase, Vercel, Anthropic, Resend, GitHub) themselves.

## Handling user data
Never include real personal data (resumes, CNIC numbers, contact details) in reports, issues, or test fixtures.
